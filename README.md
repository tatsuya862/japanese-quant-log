# Quant Log JP

お金・時間・集中力・判断力を可視化し、人生の資源を整える「Quant Log」の無料公開サイトです。無料記事、セルフチェック、金融マーケット情報を提供します。

## 公開構成

- ルートと `docs/` は公開用のミラーとして扱い、共通ページ・スクリプトを変更する場合は両方を確認する。
- `family-meal-planner.html` は、母親1名による7日間の利用検証を目的とした献立支援プロトタイプ。記録は端末内のブラウザにだけ保存し、外部送信しない。
- 有料メンバーサービスは2026年7月19日に終了。新規登録・決済導線を再設置しない。
- 問い合わせ受付は2026年11月6日に再開。公開ページのフォームは、入力内容からメールアプリを開き、`quantlog.tatsuya@gmail.com`宛ての下書きを作成する。入力内容はサイト側で保存・直接送信しない。
- 旧決済APIは終了レスポンスを返し、公開ページからStripeへ遷移させない。
